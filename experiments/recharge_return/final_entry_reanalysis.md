# v0.7.1 — Retrospective final-entry candidate

用户授权对v0.7.0全部已学习pilot轨迹离线重算。此为观察旧数据后提出的新候选定义，探索性、非预注册/正式结果；不替换旧episodes、模型、训练环境或原检测器。

主候选：4×4无任务区；寻找最后一次外→内跨界，且之后直到真实episode终止始终在区内。以跨入后的坐标为入口参考，后续在正电量状态下距离dock至少净减少2格（不是累计向站次数），才回记该进入步为onset。允许区内反向移动，无固定8步窗口；推进达到时刻单列progress_met_step，不能称为当时已知的在线确认。最终确认只能在episode结束后完成。进入后再退出的候选被排除；无最终进入、未足够推进、不完整轨迹不确认。确认后耗尽保留事件，耗尽当步才达到净推进不确认；零工作到站独立保留，事件不等于任务成功。

固定辅助敏感性：区域5×5；净推进1/2/3格，全组合报告，不按方向选阈值。主对比始终为4×4、2格。比较旧/新同场景事件数、恢复与丢失事件、改时事件、确认后退出和再工作、三seed配对PROD−RES、布局分层和双方成功子集。保留全部分母与失败，不把缺事件填成无限时间。输入完整性核对九个600k最终模型、源输入hash、每组333场景及原检测复算。输出独立目录并拒绝覆盖。代表例子仅用于解释，不作为挑选模型或场景依据。

边界测试：区内反向后恢复、进入退出再进入、仅进入即耗尽、推进足够后耗尽、重复来回不累加净推进、不完整轨迹。该定义识别最终持续接近阶段，不能区分内部意图，也可能让途中失败比到站更难获得确认。学习效率问题不会因重定义消失。
