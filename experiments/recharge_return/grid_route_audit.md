# Grid route feasibility audit — v0.6.2

这是训练前的候选设计检查，不替换 v0.6 的训练环境或正式协议，不构成 learned-policy 证据。用户已授权验证可行路线的产出、储备和 ONSET 权衡。项目没有 idea_report/implementation，本文承担本次独立诊断的设计与实现说明。

## Fixed candidate before calculation

- 10×10 可通行格，无内墙；坐标为 (x,y)，左上 (0,0)，右下终点 (9,9)。
- 六个一次性任务 A=(1,2)、B=(3,1)、C=(2,5)、D=(5,3)、E=(4,8)、F=(8,4)，每个 WORK 完成 1 单位；路过不自动完成。
- 右下无任务区域分别检查 x,y≥6（4×4）和 x,y≥5（5×5），同一批路径仅重算检测时间，不改变奖励或路线。
- 四向移动每步 1 电量，WORK 3.5，容量60，初始电量预先固定24/32/40/60，最长300步。到零优先耗尽，正电量到站终止，零工作到站单列。
- 奖励及 gamma 从 pilot_line_masked_600k.yaml 读取：每步使用动作后 battery−Manhattan_distance 计算 reserve deficit，生产、储备、时间、到站/空返/耗尽项全部逐步折扣累计。
- 电量16无法走完18步最短路线，因此不复用旧一维电量网格。本候选没有随机天气、实际充电或再出发。

## Scope of enumeration

枚举六任务所有有序子集（含零任务）；每段采用 x 后 y 或 y 后 x 的曼哈顿最短路线，两种全程统一规则均保留。记录实际执行的原子动作，提前耗尽即停止。路过未选任务可不工作。该有限路线集合不覆盖所有最短路线组合、绕行、重复访问或任意 MDP 策略，因此只能称“枚举集合内最佳”，不能声称全局最优或不同偏好必然一致。失败路线与空返路线仍计分并进入 unrestricted 排名；另报成功且有工作路线的排名。

ONSET 候选为进入无任务区的移动；包含进入步在内8步内至少3次距离下降，确认前离区、距离上升、WORK 或耗尽拒绝。确认后失败仍保留 ONSET。到站前先处理当步推进是否完成确认。另记进入后直到终止不再离区的 final_entry（仅辅助，不能把一进入就耗尽当成确认）。保留所有并列最佳路线的 ONSET 范围、任务量和路径数，避免任意 tie-break 制造时间差。

## Outputs and checks

`python -m scripts.audit_grid_routes` 生成独立 outputs/recharge_return_v0.6.2_grid_audit 下的 routes.jsonl、summary.json、report.md；输出保留完整设定、配置哈希、执行路径、三组逐项回报和胜出路线。检查能量守恒、折扣奖励分解、零电量到站优先耗尽、ONSET 进入/退出/确认后失败及枚举覆盖。不使用 held-out，不训练或修改权重，不按排序挑地图。本次结果只用于判断这个具体候选值得如何继续验证。

## Verified findings — 2026-09-26

每档电量3914条完整计划路线，四档合计15656条；失败时实际执行前缀可能重复，这不是15656个独立统计样本。包括失败与空返后的全体最佳和成功子集最佳在四档均一致。

| 电量 | RES 最佳任务序列 | BAL / PROD 最佳任务序列 | 4×4 ONSET（RES；BAL；PROD） |
|---|---|---|---|
|24|E 或 F|BAL:E或F；PROD:A|15–16；15–16；16|
|32|A C E|A C E|17–18；17–18；17–18|
|40|A B D F|A B D F|20–21；20–21；20–21|
|60|A B D F|A B D F C E|20–21；34–35；34–35|

区间是等回报轴顺序路线的事件时间集合，不是置信区间。相同轴顺序下电量60的差为14步；跨所有并列路径为13–15步。换5×5区域后所有这些最佳路径的ONSET提前1步，条件关系不变。

电量60时，四任务方案走20格、WORK4步，24步到站、电量26；六任务方案走32格、WORK6步，38步到站、电量7。两条路线累计储备扣分都是0！现有安全阈值仅4，两个方案全程均未触发；区别来自生产收益相对于共同时间成本及折扣到站奖励的权衡，不足以支持“RES由于储备风险较高而提前返航”的解释。

六任务相对四任务的折扣生产项增加1.510125，共同项下降0.415619；RES加权后净变化−0.038088，BAL +0.528209，PROD +1.094506。RES的两方案差很小，不能据此声称训练后稳定分离。24电量下三组均完成1任务、剩2.5电量，但RES/BAL选靠近终点的任务，PROD选较早任务，体现逐步奖励和折扣时序影响。

结论：本候选确有路线选择与较大onset差的可能，但低电量32/40的枚举最佳仍相同，BAL/PROD大多不分离；高电量差不是储备惩罚驱动。不足以确认三偏好分离、全局最优、学习可行性或正式假设。下一步应先决定研究目标是产出—时间权衡还是产出—储备权衡，再评估是否需要修改任务奖励，不能直接把当前差异当成功证据。
