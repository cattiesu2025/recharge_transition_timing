# Grid sweep and learning pilot — v0.7.0

2026-09-27，用户授权连续电量、跨布局可行性检查及后续学习验证。研究对象为任务层面充电接近ONSET；不要求差异必须由储备扣分引起。旧v0.6训练和输出继续保持独立。

## Fixed design before results

10×10可通行区，起点(0,0)、到站终止点(9,9)，无内墙；每任务一次WORK；现有移动1、工作3.5、电量容量60、300步、gamma0.99及全部奖励原样保留。主ONSET为4×4区域进入后8步内至少3次持续向站推进；5×5仅敏感性，同路径重算。最后WORK是辅助，不能替代ONSET。

电量24–60的全部37个整数，不删除无效应电量。布局：原六任务布局，加顺路/绕行两类×4/6任务×固定生成seed9101/9102，共9布局。顺路：从(0,0)交替向右/下至(4,4)，再向右至(9,4)的单调路径上，排除起点后无放回采样。绕行：左下条带x=0..3,y=6..9和右上条带x=6..9,y=0..3各采样一半任务，迫使跨两臂做任务时存在绕行。生成与排序只依赖坐标和seed，不读取奖励/ONSET。所有任务在5×5无任务区之外。完整manifest在计算前保存并hash。

枚举有序任务子集和两种全程轴顺序最短路线，保留失败/空返计分；非全局最优。所有路线计划保存，按路线×电量保存折扣生产/储备/共同项、终局、工作数、剩电、ONSET、最后WORK。相同失败前缀不是独立样本。汇总全体与成功路线最佳，记录所有并列最佳ONSET集合、严格次优回报差、最佳集合外最近的不同任务数方案差。若任一最佳无ONSET，不计算可分离；若PROD最早ONSET仍晚于RES最晚，记严格正分离；反向同理；其余记重叠或缺事件。阈值和集合不能按效果选择。

## Learning implementation

新增独立MiniGrid多任务环境（12×12含外墙，10×10可通行）。原子动作上/下/左/右/WORK，mask仅限制边界与已完成/不存在任务，不依据电量强制返航。完整观测位置、电量、时间、所有格子的剩余任务、5个mask。到零优先耗尽，正电到站终止，空返单列。

复用masked Double DQN，新增可覆盖mask维度支持，保持旧环境默认行为。三条件×4100/4101/4102，最终固定600000步、既有超参数，不筛checkpoint。每episode使用按seed和episode索引生成的共同场景序列；训练任务按上述几何规则用独立seed随机生成，4或6任务、电量24–60，评估使用预先固定9布局×37电量。评估布局不作训练固定样本，随机生成偶然重合不主张严格未见，全部是development pilot，非held-out/formal。

先跑单元测试和短训练链路；完整pilot使用独立Katana九任务数组，若本机可完成则可本地运行，不能把短训练冒充600k。评价保存每个seed全333场景、逐步轨迹、模型/设定hash、成功/空返/耗尽/无事件、任务量与ONSET。保留全部seed，聚合只做描述，不输出正式p值。路线枚举对照可诊断回报质量，但仍是有限参考集合。

## Validation

验证旧v0.6.2四档结果复现、vectorized评分与独立原子模拟一致、布局合法和生成重现、ONSET并列集合分类，以及MiniGrid与路线模拟逐步对齐、mask和终局、模型保存重载和评估完整性。源码版本清单只包含源码、配置/设计、测试和脚本，不含输出及本地笔记。
